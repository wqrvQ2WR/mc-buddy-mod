# Buddy

같이 놀아주는 NPC 친구를 추가하는 Fabric 모드 (Minecraft 1.21.1).

## 사용법

1. "친구 소환 부적" (Buddy Summoning Charm) 아이템을 도구 탭 크리에이티브 인벤토리에서 꺼내거나 `/give @s buddy:buddy_charm`
2. 우클릭하면 앞에 친구(Buddy)가 소환되고, 바로 나를 주인으로 인식해 따라다님
3. 친구를 우클릭 → 랜덤 응원 메시지 채팅
4. 웅크린 채 우클릭 → 앉기/일어서기 토글
5. 근처 몬스터(크리퍼 제외)를 자동으로 공격하고, 내가 맞으면 반격해줌
6. 리드줄로 묶어서 데리고 다닐 수 있음
7. 내가 블록을 캐면, 반경 32블록 안에 있는 내 친구가 자기 주변(반경 4블록) 같은 종류 블록을 하나 같이 캐서 드랍 아이템을 바로 내 인벤토리로 줌 (친구가 곡괭이 등 도구를 들고 있으면 그 도구 기준으로 드랍 계산)
8. 친구와 상호작용할 때 손에 갑옷이나 도구/무기를 들고 있으면 그 부위에 장착시켜줌 (기존에 장착된 아이템은 나에게 돌려줌)

빵(`minecraft:bread`)을 야생에서 자연스레 소환된(길들지 않은) 친구에게 주면 길들일 수도 있음 — 단, 기본 소환 방식은 이미 길들인 상태로 나옴.

## 빌드

```
./gradlew build
```

결과물: `build/libs/buddy-1.0.0.jar`

## 필요 사항

- Minecraft 1.21.1
- Fabric Loader 0.19.3 이상
- Fabric API 0.116.15+1.21.1

## 참고

- 엔티티 텍스처(`src/main/resources/assets/buddy/textures/entity/buddy.png`)와 아이템 아이콘은 임시 placeholder임. Blockbench/그림판 등으로 원하는 모습으로 교체 가능 (64x64 스티브/좀비 UV 레이아웃 그대로 사용).
